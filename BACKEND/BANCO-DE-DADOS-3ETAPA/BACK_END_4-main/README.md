# 🚀 Curso Back-End 4 (Node.js Avançado)

Bem-vindo ao repositório oficial da disciplina **BACK_END_4**. 
Aqui você encontrará todos os materiais, projetos e documentações utilizados em sala de aula.

## 📂 Estrutura do Repositório

O repositório está organizado nas seguintes pastas principais:

### 1. `aulas/`
Contém os slides, tutoriais em Markdown e exemplos didáticos apresentados durante as aulas teóricas.
- **Aula_Documentação**: Como documentar APIs com OpenAPI/Swagger.
- **Aula_JWT**: Autenticação de usuários usando tokens JWT.
- **Aula_upload**: Upload de arquivos e imagens usando Multer.

### 2. `projetos/`
Contém as APIs completas desenvolvidas pela turma ao longo do semestre.
- **[Sabor Digital](./projetos/sabor_digital/)**: Uma API robusta de delivery/restaurante com autenticação, upload de fotos e documentação automatizada.

---

> **Aviso aos Alunos**: Para rodar o projeto *Sabor Digital*, navegue até a pasta `projetos/sabor_digital`, instale as dependências com `npm install` e inicie o servidor com `npm run dev`. Todas as instruções específicas estão dentro do repositório do projeto.
