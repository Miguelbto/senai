Masterclass: Arquitetura, Infraestrutura e Deploy

O Fim do Localhost

O maior pecado de um desenvolvedor júnior é dizer: "Na minha máquina funciona".

Deploy (Implantação) não é apenas copiar arquivos. É garantir que o seu sistema sobreviva no ambiente hostil e imprevisível da internet.

Os Tipos de Hospedagem

IaaS

Infrastructure as a Service. Você aluga a máquina vazia. Tem que configurar o Linux, o Firewall e instalar o Node.

AWS EC2, DigitalOcean.

PaaS

Platform as a Service. Você apenas envia o código. A plataforma cuida de toda a infraestrutura por você.

Render, Heroku, Railway.

On-Premise

Você compra o servidor físico e cuida do hardware. Se faltar luz, o sistema cai.

Os 6 Pilares do Deploy (1/2)

1. Empacotamento

Gestão estrita de dependências (lockfiles), variáveis de ambiente isoladas (.env) e uso de Docker.

2. Infraestrutura

A escolha entre PaaS, IaaS ou Serverless. Em alta escala, uso de orquestradores (ex: Kubernetes).

3. Banco de Dados

Bancos na nuvem, rotinas de backup rígidas e execuções automatizadas de Migrations e Seeders.

Os 6 Pilares do Deploy (2/2)

4. Rede & Segurança

Configuração de Domínio, certificados SSL/TLS (HTTPS) e Load Balancers/Proxy Reverso (ex: Nginx).

5. Automação (CI/CD)

Pipelines de testes e estratégias de entrega seguras (Blue/Green, Canary Releases).

6. Observabilidade

Health Checks, APM (monitoramento de performance) e alertas (O famoso pager de madrugada).

A Porta Dinâmica

Em produção, nós não somos donos do servidor. A nuvem decide qual porta o Node.js deve usar.

Se você colocar `app.listen(3000)`, seu app vai quebrar na nuvem.

O jeito Sênior:

const PORT = process.env.PORT || 3000;

A Arquitetura da Nossa Aula

Usaremos uma solução híbrida muito requisitada pelo mercado: Nuvem distribuída.

O Motor (Render)

Nossa API Node.js será hospedada no Render. Ele ficará encarregado do CI/CD, SSL e de ler nosso repositório no GitHub.

O Banco (Aiven)

Como utilizamos MySQL nativo, nosso Banco de Dados ficará na nuvem pelo Aiven.io. O Render se conectará nele pela internet via `.env`.
