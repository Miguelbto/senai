# aula05-testes-starter

Projeto base da Aula 05 — Testes Unitarios com Jest.

Durante a aula vamos escrever os testes de `utils/calculos.js` juntos. Depois, complete o exercicio em `ENUNCIADO.md` escrevendo os testes do `ProdutoRepository`.

## Como comecar

```bash
npm install
npm test
```

## Estrutura

```
utils/
  calculos.js              - funcoes de calculo da lanchonete
repositories/
  ProdutoRepository.js     - repositorio de produtos em memoria
```
