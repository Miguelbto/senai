Como Ficam as Consultas no Backend Agora
1. Desativar um Produto (Rota DELETE /api/produtos/:id)
SQL
UPDATE produto 
SET ativo = FALSE, deleted_at = NOW() 
WHERE codigo_produto = ?;
2. Listar Apenas Produtos Ativos no Catálogo (Rota GET /api/produtos)
SQL
SELECT * FROM produto 
WHERE ativo = TRUE;
3. Restaurar um Produto Excluído por Engano (Rota PATCH /api/produtos/:id/restaurar)
SQL
UPDATE produto 
SET ativo = TRUE, deleted_at = NULL 
WHERE codigo_produto = ?;
